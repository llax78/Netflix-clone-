# 🎬 Netflix Clone

A responsive **Netflix-inspired web application** built during my **Frontend Developer Internship at Alfido Tech**. This project helped me strengthen my skills in frontend development, responsive UI design, and creating real-world web interfaces.

## 🚀 Features

* 🎥 Netflix-inspired user interface
* 📱 Responsive design for different screen sizes
* 🖼️ Movie/show cards with posters and details
* 🔍 Clean and user-friendly layout
* 🎨 Modern dark-themed interface
* ⚡ Interactive frontend components

## 🛠️ Tech Stack

* **HTML**
* **CSS**
* **JavaScript**

## 📂 Project Purpose

This project was developed as part of my **Alfido Tech Frontend Developer Internship** to gain practical experience in building a real-world streaming-platform-style interface.

* Structuring frontend projects

* Improving user experience and visual design
